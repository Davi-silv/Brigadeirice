## Sobre o projeto

A **Brigadeirice** é uma landing page para uma marca de doces gourmet. Foi desenvolvida com **HTML5, CSS3 e JavaScript puro**, com foco na apresentação visual dos produtos e na facilidade de contato para pedidos.

O projeto demonstra desenvolvimento de interfaces responsivas sem dependência de frameworks.

## Seções da página

| Seção | Finalidade |
| --- | --- |
| Apresentação | Destaque da marca e chamada principal |
| Sabores | Vitrine de brigadeiros gourmet |
| Essência | Diferenciais e proposta de valor |
| História | Informações sobre a marca |
| Pedido | Chamada para contato via WhatsApp |

## Recursos de interface

- Layout responsivo;
- Navegação com menu mobile;
- Animações e interações em JavaScript;
- Apresentação de produtos e imagens;
- Direcionamento para contato pelo WhatsApp.

## Tecnologias

- **HTML5:** estrutura da página;
- **CSS3:** estilização e adaptação a telas diferentes;
- **JavaScript:** menu, animações e interações.

## Como executar

Sem instalação de pacotes ou compilação:

```bash
git clone https://github.com/Davi-silv/Brigadeirice.git
cd Brigadeirice
python3 -m http.server 5173
```

Acesse **http://127.0.0.1:5173**. Alternativamente, abra o arquivo `index.html` no navegador.

## Contexto técnico

O uso de tecnologias nativas permite uma estrutura pequena, edição direta de conteúdo e publicação em hospedagens estáticas. O projeto pode ser utilizado como demonstração de construção de landing pages e comunicação visual para pequenos negócios.
