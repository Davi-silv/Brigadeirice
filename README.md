# Brigadeirice

Landing page da **Brigadeirice** — doces gourmet feitos com ingredientes selecionados, embalagem sofisticada e sabor que encanta.

## Sobre o projeto

Página institucional em HTML5, CSS e JavaScript puro, sem frameworks. Apresenta o produto, os diferenciais da marca e o contato para pedidos via WhatsApp.

## Estrutura

```
Brigaderice/
├── index.html      # Estrutura da página
├── styles.css      # Estilos e layout responsivo
├── script.js       # Menu mobile, scroll e animações
└── imagem/         # Fotos do produto e da marca
```

## Seções

- **Hero** — identidade visual e chamada principal
- **Sabores** — vitrine dos brigadeiros gourmet
- **Essência** — pilares da marca (ingredientes, qualidade, amor, embalagem)
- **História** — quem está por trás da Brigadeirice
- **Pedido** — contato direto pelo WhatsApp

## Como visualizar

Abra o `index.html` no navegador ou sirva a pasta localmente:

```bash
python3 -m http.server 5173
```

Acesse: [http://127.0.0.1:5173](http://127.0.0.1:5173)
